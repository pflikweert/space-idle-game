# Railgun card art v1

Generated using built-in ImageGen on 2026-09-10. Hero references the own silver/navy gunship intact source. Piercing, twin, overcharge, shatter and rampage reference the generated hero to maintain identity, cyan lighting and painted materials. No embedded text or frames. Original generated PNGs are preserved in `sources/`; runtime copies are resampled to 1024×1024 using sips. Gameplay sprites are untouched.
